# Restro AI

This project is a full restaurant management and AI assistant workspace with a backend service, a frontend app, and supporting docs and scripts.

## Project structure

- backend/ - API server, services, models, and business logic
- frontend/ - web frontend application
- docs/ - project documentation and archived legacy notes
- scripts/ - utility scripts and automation helpers
- project/ - project-specific assets and planning files
- seo-system/ - SEO-related modules
- memory/ - local memory notes and workspace context

## Main entry points

- Backend: backend/main.py or backend/server.py
- Frontend: frontend/
- Documentation: docs/
- Project notes: project/

## Recommended workflow

1. Start the backend from backend/
2. Start the frontend from frontend/
3. Keep new docs in docs/ and avoid cluttering the root folder
4. Use the archive folder for old or temporary material
